    Frequently Asked Questions

    How do I participate in NTE events?

    Most events are accessed through the in-game event page. Limited-time events have specific start and end dates, so check our Events page regularly to avoid missing deadlines. Some events require completing prerequisites like story chapters.

    What rewards do events give?

    Events typically offer premium currency, upgrade materials, exclusive cosmetics, and sometimes limited-time characters or weapons. Login events give daily rewards for consistent play, while challenge events offer bigger rewards for skilled gameplay.

    Are event rewards exclusive?

    Some rewards are event-exclusive (cosmetics, titles, special items) while others are standard resources available elsewhere. We recommend prioritizing exclusive rewards first, then collecting standard resources.

    How long do events last?

    Event duration varies: login events typically run 2-4 weeks, story events 4-6 weeks, and challenge events 2-3 weeks. Limited banners usually run for 2 weeks. Check the event calendar on our site for exact dates.
